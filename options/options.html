AI Provider

StudyLens sends extracted text (from a webpage or an uploaded file) to this AI service only when you use a study feature. It never sends anything automatically.

Get an OpenAI key at platform.openai.com, or a free Gemini key at aistudio.google.com/apikey.

Your key is stored only on this device (chrome.storage.local) and is sent directly to your AI provider - never to StudyLens's developers. For a personal, local extension this is normal, but a key stored in a browser extension is not as protected as one kept on a private server. See the README for details.

Privacy

StudyLens only reads a webpage when you click "Scan Current Page," and only reads an uploaded file when you choose one. It does not track your browsing history, watch other tabs, or use your camera, microphone, or location.

Uploaded files (PDF, Word, PowerPoint, TXT, Markdown, CSV, RTF) are opened and read entirely inside your browser, using local parsing libraries bundled with the extension - the file itself is never uploaded anywhere. When you use a study feature (Summary, Key Points, Full Reviewer, Highlight), the extracted text - from the webpage or the file - is sent to the AI provider configured above, the same way it is for a scanned webpage.

Extracted text, results, and highlights exist only in the side panel while it's open and are not saved anywhere by StudyLens.
