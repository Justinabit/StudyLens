AI provider

StudyLens sends extracted text (from a webpage, a file, or text you selected) to this provider only when you use a study tool. It never sends anything on its own.

Get a key ↗

Leave blank to use the recommended model shown. Change it if your provider retires a model name.

Your keys are stored only on this device (chrome.storage.local) and are sent directly to the provider - never to StudyLens's developers. A key stored in a browser extension isn't as protected as one kept on a server, so don't use StudyLens on shared computers with a key that has a large spending limit.

Privacy

StudyLens only reads a webpage when you click "Scan," and only reads a file when you choose one. It doesn't track your browsing, watch other tabs, or use your camera, microphone, or location.

Uploaded files (PDF, Word, PowerPoint, TXT, Markdown, CSV, RTF, HTML) are read entirely inside your browser using libraries bundled with the extension - the file itself is never uploaded. When you use a study tool, the extracted text is sent to the AI provider above.

Your current study session (source text and results) is kept in Chrome's memory-only session storage so it survives closing the panel. It's cleared when you close the browser, and never written to disk.
